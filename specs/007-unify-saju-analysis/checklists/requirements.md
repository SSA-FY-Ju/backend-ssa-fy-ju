# 명세 품질 체크리스트: 전체 초기화 결정 반영

이 체크리스트는 문서의 요구사항 범위를 확인한다. 실제 원본 제공·DB 대조·초기화·배포가 완료됐다는 뜻은 아니다.

## 문서 확인

- [x] 전체 초기화가 이전 보존 설계를 대체함을 명시했다.
- [x] 분석·피드백·프로필·일일 사용량의 삭제 대상과 계정·인증 유지 범위를 명시했다.
- [x] 피드백 원본 모든 행·모든 컬럼, 무조인·무가공·무마스킹·무필터와 탈퇴 사용자 포함을 FR-017/SC-007에 명시했다.
- [x] 세 유형 원본 총수·별도 SAJU 접근수·사용자별 유형 수·산정 기준을 FR-019/SC-009에 명시했다.
- [x] 자료 제공·DB 대조·운영자 확인 전 초기화 금지를 명시했다.
- [x] 쓰기 중단부터 배포까지의 순서를 FR-020과 전환 절차에 명시했다.
- [x] 보고서 양식과 실제 SQL은 Git에서 제외된 로컬 문서(`specs/007-unify-saju-analysis/local/reset-runbook.md`)로 제공하며 저장소에는 포함하지 않는다. 커밋 대상 문서에는 정의만 남기고 개인정보 결과물은 로컬에만 보관한다.
- [x] 새 구조의 빈 상태·모든 유형 만세력 필수·UNIQUE인 단일 피드백 FK(분석당 0..1개)·created_at 기준·관리자 단일 집계를 정의했다.
- [x] 과거 이력 삭제·숫자 ID 자동 증가 재발급·과거 번호 보정 없음·당일 쿼터 재설정 영향을 명시했다.
- [x] 폐기된 결정은 research.md에서 초기화 결정으로 폐기됐음을 표시하고 이유를 남겼다.

- [x] 만세력 계산 데이터는 ManseData record의 data_json 하나로 저장하고 기존 검증을 유지한다.

- [x] 피드백의 중복 유형 컬럼·요청 필드를 제거하고 연결된 saju.analysis_type으로 허용 여부를 검증한다. 기존 원본 내보내기는 모든 컬럼을 유지한다.

- [x] 사용자 기본 프로필은 NULL 허용 FK로 두고 실제 분석 프로필·직접 소유권과 구분한다. 명시적 기본값 저장과 다른 출생정보 분석을 지원하며 공유 프로필·과거 결과·진행 중 입력은 변경하지 않는다.

- [x] 관리자 회원 관리·사용량 조정·대시보드·피드백 목록/count/상세/통계를 작업·회귀 범위에 포함했다.
- [x] 관리자 응답 필드·type 필터·SAJU 거부 예외와 피드백 작성 요청 필드 제거를 구분했다.
- [x] 새 피드백 user_id NOT NULL·소유자 일치와 원본의 NULL 행 포함을 구분했다.
